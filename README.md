# 🏨 Villa Valore Hotel Reservation System

A comprehensive Property Management System (PMS) designed for Villa Valore to handle client room bookings, manage dynamic room occupancy statuses, track guest records, and process administrative checkouts.

## 🤝 Teammate Collaboration & My Contributions
This application was built as part of a collaborative group project. My specific engineering contributions focus heavily on backend operations and structural logic.

**My Specific Responsibilities:**
* **Relational Database Engineering:** Designed and optimized the MySQL schema to handle room availability matrices and prevent booking conflicts.
* **Reservation Engine Logic:** Programmed the backend core components (PHP) responsible for computing night stays, booking confirmations, and checkout updates.
* **Admin Dashboard Viewports:** Created responsive administrative views allowing desk agents to visually audit room check-ins seamlessly on desktop and mobile.

## 🛠️ Tech Stack
* **Backend:** PHP
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, Bootstrap Framework
* **Tools:** XAMPP, VS Code, Git, GitHub

## ✨ Core Features
* **Dynamic Booking Management:** Streamlined workflow for creating, updates, and archiving guest reservations.
* **Room Status Tracker:** Visual matrix updating rooms as Available, Occupied, or Under Maintenance instantly.
* **Data Sanitization:** Implemented strict input validation to keep system logs safe from SQL injections and structural breaks.
